# SaasForArtisans
SaaS pour artisans : création de devis, factures, base client et tableau de bord associé.

## Déploiement Vercel

Consultez le guide détaillé dans `docs/DEPLOYMENT.md` pour configurer les variables d'environnement, préparer PostgreSQL et lancer un déploiement fiable sur Vercel. Vérifiez notamment que `DATABASE_PROVIDER` est bien positionné sur `postgresql` dans Vercel pour éviter les erreurs de déploiement.
